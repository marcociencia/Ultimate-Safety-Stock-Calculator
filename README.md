# 📦 Ultimate Safety Stock Calculator

> **Bulletproof your supply chain! This interactive calculator visualizes demand & lead time variability in real-time. Optimize inventory, prevent stockouts, and master resilience with dynamic bell curves. Plug-and-play for operations pros!**

![Supply Chain Calculator](https://img.shields.io/badge/Operations-Research-blue) ![Version](https://img.shields.io/badge/Version-1.2-green)

This project provides an interactive, visual tool that computes safety stock using both the **Standard Formula** (demand variability only) and the **Combined Formula** (demand + lead time variability). 

🔗 **See the project applied live here:** [Mathematics Supply Chain Resilience: Optimal Safety Stock](https://globalnowview.com/mathematics-supply-chain-resilience-optimal-safety-stock/)

## ✨ Key Features
- **Real-Time Data Visualization:** Watch the probability distribution curve adapt dynamically based on your inputs.
- **Advanced Calculations:** Implements mathematical logic to determine the perfect balance between risk and safe zones.
- **Highly Modular:** Built with performance in mind, cleanly separating logic, styling, and scripts.
- **Custom UI:** Sleek UI elements with native SVG integration and gradient backgrounds.
